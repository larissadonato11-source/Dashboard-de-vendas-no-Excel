# Dashboard de vendas no Excel


Este repositório contém um Dashboard Interativo de Vendas desenvolvido no Microsoft Excel em desenvolvimento na aula prática da DIO, projetado para transformar dados brutos em insights visuais e estratégicos.

🚀 Funcionalidades e Destaques
Indicadores Chave (KPIs): Visualização rápida do faturamento total, volume de vendas, ticket médio e atingimento de metas.

- Análise Temporal: Acompanhamento do desempenho de vendas por período (mensal/anual).

- Filtros Interativos: Segmentação dinâmica de dados por região, categoria de produto através de tabelas dinâmicas e segmentadores.

- Design Funcional: Layout limpo, intuitivo e focado na facilidade de leitura dos dados.

🛠️ Tecnologias e Recursos Utilizados
Microsoft Excel

- Tabelas Dinâmicas

- Gráficos Dinâmicos

- Segmentação de Dados
